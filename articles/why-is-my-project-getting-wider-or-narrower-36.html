Why Is My Crochet Project Getting Wider or Narrower?

Find where a project’s stitch count first changes, then check edges, turning chains, increases, and decreases.

A piece that grows or narrows can reflect stitch-count changes, tension, or both. Measuring at intervals helps locate when the drift began.

Before you begin

Keep the pattern and row count nearby. For long repeats, use markers at repeat boundaries as well as edges.

Step-by-step instructions

  1. Measure the width and count stitches on the current row; compare with a recent row and the pattern.
  2. Find the first row where the count changed and inspect its first and last stitch.
  3. Check whether the turning chain counts and whether the pattern calls for an increase or decrease.
  4. If count is correct but width changes, compare tension and gauge before continuing.

What to check

Trace the change back one row at a time

Do not force edges flat by stretching. A count change suggests a skipped or added stitch; correct where it began if the edge shape matters.

Frequently asked questions

Why is my rectangle getting wider?

Look for extra stitches at row ends, including a turning chain worked when the pattern does not count it.

Can tension change width with the same count?

Yes. Larger or looser stitches can change dimensions even with an unchanged stitch count.

Compare the stitch count across rows

For project getting wider or narrower, use this as the starting rule: compare stitch counts row by row and inspect the first and last stitch before changing tension. The publisher’s key and terminology tell you how to read that specific set of instructions. Read the relevant instructions before beginning and keep them nearby as you work. If a general tutorial and the pattern give different directions, follow the pattern’s stated convention; another project may use a different method.

Check the first and last stitch

Before proceeding, confirm whether the pattern increases, decreases, or counts the turning chain. Write any project-specific choice in your notes so you can apply it consistently. If the pattern or label leaves the detail unclear, look for its own key or maker guidance rather than assuming that another project follows the same convention. This short check can prevent a small misunderstanding from affecting the rest of the work.

Use markers to find the edge

A practical way to apply project getting wider or narrower: Take one short instruction from a pattern and mark edge stitches and record each row total. Mark the line, chart row, or repeat where you stopped, then check that the next step follows from the key and count. Working through a small section on paper or in a swatch can expose unfamiliar notation before it affects a larger part of the project.

Separate count drift from tension

A common mistake in project getting wider or narrower is adding or dropping edge stitches while turning. Watch for this sign: the sides drift even though the middle pattern repeat is correct. That can shift the stitch, repeat, or chart symbol and alter the instruction sequence. Compare the recent work with the pattern and locate the first point where they differ. Correct that detail before continuing; stretching the fabric or adding an unplanned step can hide the cause without fixing it.

Locate the first row that changes

If the sides drift even though the middle pattern repeat is correct, first check whether the pattern increases, decreases, or counts the turning chain. Then compare the terminology, key, repeat marks, and row or round count with what you actually have. Change one thing at a time so you can tell whether it addresses the problem. If the instructions and materials match but the result still differs, use the project’s gauge, sizing, substitution, or care notes as relevant; those are more useful than a universal fix.

Correct the cause before blocking

Remember: find the point where the count changes, then correct that cause. A publisher’s notation is specific to its pattern, so write down the terminology and symbols you have confirmed. If you choose an alternative, record it and compare a small sample or written step before applying the change across the project.

Keep the project width consistent

To make project getting wider or narrower easier to repeat, use this sequence: mark edge stitches and record each row total, inspect the result, and only then continue. At first, slow down at the point where the pattern changes direction, begins a new round, or starts a repeat. A removable marker or brief row note can hold your place while you learn the construction. Once the sequence is clear, you can work more steadily without guessing which loop or instruction comes next.

Conclusion: Project getting wider or narrower

Keep this lesson in mind: find the point where the count changes, then correct that cause. Keep the verified key and terminology beside the instructions. If the stitch count is correct but width still changes, compare gauge and tension before adding or removing stitches. Correct the first source of drift.
