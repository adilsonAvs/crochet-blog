Crochet Tools & Calculators

Use your pattern and swatch measurements to make practical estimates. The tools run in your browser, do not send values to a service, and do not promise exact finished sizes or yarn use.

Crochet Gauge Calculator

Enter a stitch count and width from a swatch made with the project stitch. Leave the pattern multiple and edge fields blank unless the pattern specifies them.

If you enter a multiple, enter the fixed edge count too; enter 0 if the pattern has no fixed edge stitches. Blank fields mean no repeat adjustment.

Enter your swatch count and widths to see the estimate.

Formula and example

Stitch gauge = stitches counted ÷ measured width. Estimated stitches = stitch gauge × desired width, rounded up to a whole stitch. If a pattern gives a repeat multiple and fixed edges, the calculator rounds up to the next valid count: multiple × ceiling((estimate − edge stitches) ÷ multiple) + edge stitches.

Example: 20 stitches across 4 inches gives 5 stitches per inch. A 12-inch target estimates 60 stitches before any pattern-repeat adjustment. This is arithmetic, not a tested project size.

Crochet Yarn Estimator

Use the total yardage or meterage stated by the pattern and the length listed on one skein. Enter both in the same unit. Dimensions alone are not enough for a reliable yarn estimate, so this tool does not extrapolate consumption from area.

Leave the margin blank to apply 0%. Any margin you enter is your own choice; the site does not recommend a universal extra amount.

Enter pattern yardage and skein length to see the skein count.

Formula and example

Skeins = ceiling((pattern yardage × (1 + optional margin ÷ 100)) ÷ yardage per skein). Example: 900 yards ÷ 225 yards per skein = 4 skeins before any optional margin. If the pattern does not give yardage, ask the designer or use a reliable pattern-specific source; this tool cannot infer a dependable amount from width and length alone.

Blanket Size Calculator

Enter stitch and row gauge from a swatch in the blanket stitch. Use the same selected unit for both target dimensions and both swatch measurement spans.

If you enter a multiple, enter the fixed edge count too; enter 0 if there are no fixed edge stitches. Blank fields mean no repeat adjustment. The calculator does not estimate yarn use.

Enter target dimensions and stitch/row gauge to see the estimate.

Formula and example

Stitch gauge = swatch stitches ÷ swatch width; row gauge = swatch rows ÷ swatch height. Estimated stitches = stitch gauge × target width, rounded up, then optionally adjusted to the pattern multiple and fixed edges. Estimated rows = row gauge × target length, rounded up. Calculated dimensions are the resulting counts divided by their gauges.

Example: 16 stitches across 4 inches gives 4 stitches per inch. A 40-inch width starts at 160 stitches before any repeat adjustment. These are mathematical estimates; yarn, tension, stitch pattern, borders, and construction affect the blanket.

What these calculators cannot tell you

A calculator cannot confirm whether a fabric has the drape, structure or feel a project needs. Gauge depends on your actual swatch, yarn, hook and technique. Follow the pattern’s stitch multiple, edges, turning-chain rule and care instructions. These tools provide arithmetic estimates, not tested recipes, exact yarn usage or fit guarantees.
